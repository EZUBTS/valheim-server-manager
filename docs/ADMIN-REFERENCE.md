# Valheim 1.0.21 — админ-справочник (клиент + выделенный сервер, Windows)

> Практическая справка для десктоп-менеджера выделенного сервера Valheim.
> Игра: **1.0.21**, network version **41**, Windows, dedicated server из Steam (appid 892970).
> Документ отвечает на два вопроса: **что реально можно сделать из игры** (F5-консоль) и **что можно сделать без модов** аргументами запуска и файлами. Всё, что требует модов, вынесено в отдельный раздел.

**Легенда достоверности**

| Метка | Значение |
| --- | --- |
| ✅ | Проверено по первоисточнику: официальный мануал из поставки сервера 1.0.21, бинарники игры (`assembly_valheim.dll`), либо воспроизведено на нашем сервере |
| 🟡 | Подтверждено несколькими независимыми вторичными источниками, но не проверено в бинарнике/на сервере |
| ⚠️ | Не подтверждено, противоречивые данные или вывод по аналогии — использовать осторожно |

**Как собирались данные (методика)**

1. **Реестр команд** вытащен из `server\valheim_server_Data\Managed\assembly_valheim.dll` версии 1.0.21: строки реестра `Terminal`/`Console` идут парами «имя — справка», что даёт точный синтаксис и точный текст подсказки. Это первоисточник, а не пересказ вики.
2. **Префабы предметов и существ** сверены с дампом префабов клиента (Jotunn, `JotunnLib/Documentation/data/prefabs/prefab-list.md`, 4 807 префабов). Каждый ID в `admin-items.json` проверен на существование в дампе — выдуманных нет.
3. **Аргументы сервера, формат admin-файлов и админ-команды** — из официального PDF `server\Valheim Dedicated Server Manual.pdf`, который лежит в поставке сервера 1.0.21.
4. Поведение на выделенном сервере (отказ `devcommands`) подтверждено четырьмя независимыми хостерами + наличием мода, который это лечит.

## 0. TL;DR — что реально можно удалённо без модов

| Возможность | Без модов | Как именно |
| --- | --- | --- |
| Кик / бан / разбан / список банов | ✅ | `kick`, `ban`, `unban`, `banned` из F5-консоли админа |
| Сохранение мира «по команде» | ✅ | `save` в игре админом; при штатной остановке (CTRL+C) сервер сохраняет мир сам 🟡 |
| Список игроков и их ID | ✅ | парсинг лога + F2-панель в игре |
| Выдать админку / забанить офлайн | ✅ | правка `adminlist.txt` / `bannedlist.txt` / `permittedlist.txt` + **рестарт** |
| «Бессмертие», полёт, спавн предметов, телепорт, читы | ❌ | На ванильном выделенном сервере **запрещены даже админам**. Нужен мод (Server devcommands) |
| Бесконечное здоровье/выносливость «для всех» | ❌ | Прямого способа нет. Ближайшее — world-модификаторы (урон, смерть, ресурсы), см. §4.3 |
| Бесплатная стройка / пассивные мобы / без рейдов / без карты | ✅ | Аргументы запуска `-preset`, `-modifier`, `-setkey` |
| RCON / stdin-команды | ❌ | В ванили нет ни RCON, ни чтения stdin. Только моды (§6.2) |
| Смена сложности на ходу | ❌ | Модификаторы применяются при старте сервера (мир их запоминает). Консольные `setworldmodifier`/`setworldpreset` требуют читов |

> **Главный вывод для админ-панели:** без модов максимум, что можно дать пользователю, — это (1) управление списками админов/банов, (2) world-модификаторы через аргументы запуска, (3) рестарт/сейв/бэкапы, (4) просмотр игроков из логов. Всё «читерское» (god, spawn, item, teleport) на выделенном сервере недоступно — это ограничение самой игры, а не приложения.

## 1. Как стать админом

### 1.1. Файл `adminlist.txt`

| Аспект | Значение | Достоверность |
| --- | --- | --- |
| Расположение | В каталоге сохранений: `-savedir`, если задан, иначе `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim\`. Рядом лежат `bannedlist.txt`, `permittedlist.txt`, папка `worlds_local` | ✅ мануал 1.0.21 + наш сервер: `server\savedir\adminlist.txt` |
| Создание | Сервер сам создаёт файлы при первом старте (у нас создан с шапкой-комментарием) | ✅ проверено локально |
| Формат строки | `[Platform]_[User ID]`, **регистрозависимо**, одна запись на строку | ✅ мануал: «follows the format [Platform]_[User ID] (case sensitive)» |
| Steam | `V_<SteamID64>` в 1.0; исторический `Steam_<SteamID64>` тоже принимается (после хотфикса 1.0.12) | ✅/🟡 мануал (формат) + low.ms, connecthosting (совместимость) |
| Xbox / Game Pass | `X_<ID>` | ✅ мануал («Platform_UserID») + Host Havoc |
| PS5 / Switch 2 | Свой префикс платформы (`Platform_<ID>`) | 🟡 Host Havoc, connecthosting |
| Комментарии | Строки, начинающиеся с `//` | 🟡 low.ms, wasabi; у нас в файле шапка `// List admin players ID  ONE per line` — ✅ |
| Применение | **Только после рестарта сервера** (файл читается на старте) | ✅ connecthosting, low.ms, Host Havoc |
| Кодировка | Plain text, UTF-8/ASCII, CRLF | ⚠️ явно не документировано |

Пример `adminlist.txt` для 1.0.21:

```text
// Admins
V_76561198000000001
V_76561198000000002
X_2535400000000001
```

**Проверенный нами путь** (совпадает с текущим сервером):

```text
D:\Servers\Valheim\server\savedir\adminlist.txt   ← при -savedir "D:\Servers\Valheim\server\savedir"
```

⚠️ **Ловушка `permittedlist.txt`**: это whitelist. Достаточно одной строки — и все, кого нет в списке, не смогут зайти. Мануал 1.0.21: «adding a person on the permitted list will ban everyone else from the server» ✅.

### 1.2. Что даёт статус админа на выделенном сервере

| Разрешено админу | Запрещено админу |
| --- | --- |
| `kick`, `ban`, `unban`, `banned` ✅ (мануал 1.0.21) | `devcommands` и все читы: `god`, `fly`, `spawn`, `item`, `goto`, `event`, `debugmode` ✅ |
| `save`, `info`, `ping` 🟡 (хотеры; в мануале перечислены только модераторские) | `setworldmodifier` / `setworldpreset` / `setkey` из консоли 🟡 (это dev-команды) |
| Открыть F5-консоль (нужен `-console` или настройка в меню) ✅ | Влиять на мир иначе как через рестарт ❌ |

✅ **Ключевой факт:** ванильный выделенный сервер **отклоняет `devcommands` для всех, включая админов**. Это не проблема прав и не лечится файлами.
Источники: [low.ms](https://low.ms/knowledgebase/valheim-admin-commands) («Valheim turns devcommands off on dedicated servers, so god, fly, spawn and the rest won't do anything for you even as an admin»), [connecthosting](https://connecthosting.net/blog/valheim-admin-commands-dedicated-server) («refused for everyone, admins included»), [Host Havoc](https://hosthavoc.com/en-GB/blog/valheim-console-commands-and-spawning-items), [wabbanode](https://wabbanode.com/help/valheim/how-to-use-dev-commands-on-your-valheim-server).

### 1.3. Чек-лист «добавил себя, а админки нет»

1. Сервер **перезапущен** после правки файла.
2. Файл лежит **в том каталоге**, который реально использует сервер (`-savedir`!).
3. ID скопирован из F2-панели или лога, а не набран руками; регистр и префикс совпадают.
4. Нет лишних пробелов/переводов строки в конце.
5. Не пустой ли `permittedlist.txt` (иначе «никого не пускает»).
6. Если сервер обновлялся с лаунч-версии 1.0 — обновите до 1.0.12+: там починили распознавание старых ID (`Steam_…`) 🟡.

## 2. Консоль: как открыть и что нужно

| Платформа | Как открыть | Достоверность |
| --- | --- | --- |
| Steam (Windows) | Добавить `-console` в параметры запуска → в игре **F5** | ✅ мануал/хостеры |
| Steam, свежие сборки | Чекбокс «консоль разработчика» в настройках игры (с 0.221.4) — альтернатива `-console` | 🟡 Host Havoc |
| PC Game Pass | Ярлык на `Valheim.exe` с `-console`, затем F5 | 🟡 Host Havoc |
| Xbox | LB+RB+Menu, затем A | 🟡 Host Havoc |
| PS5 / Switch 2 | Консоль недоступна (админом быть можно, командовать — нет) | 🟡 connecthosting |

Полезное в консоли:

- `help` — список команд; `help 2 4` — вторая четверть списка ✅ (текст справки из DLL).
- **Tab** — автодополнение имён префабов; это самый надёжный способ узнать точный prefab ID для текущей сборки ✅/🟡 (gamever, Host Havoc).
- В шапке консоли печатается версия и network version — у нас `Valheim 1.0.21 (network version 41)` ✅ (лог сервера).

### 4.2. Почему на выделенном сервере это не работает

`devcommands` отклоняется сервером → все команды из §4.1 недоступны даже админу ✅ (§1.2). Единственные «легальные» рычаги — world-модификаторы (§4.3) и правка мира в одиночной игре с последующим возвратом файлов мира 🟡 (connecthosting).

## 5. Выдача предметов

### 5.1. Синтаксис `spawn` (1.0.21)

```text
spawn <prefab> [amount] [level] [radius] [p/e/i]
```

Точная справка из DLL 1.0.21 ✅:

> `[amount] [level] [radius] [p/e/i] - spawn something. (End word with a star (*) to create each object containing that word.) Add a 'p' after to try to pick up the spawned items, adding 'e' will try to use/equip, 'i' will only spawn and pickup if you don't have one in your inventory.`

| Параметр | Смысл |
| --- | --- |
| `prefab` | Точный prefab ID (`Wood`, `Iron`, `SwordIron`…); можно `*`-маску по подстроке |
| `amount` | Количество (по умолчанию 1) |
| `level` | Для существ — «звёзды» (1 — базовое, 2 — одно-, 3 — двухзвёздочное) 🟡 |
| `radius` | Радиус разброса при спавне |
| `p` / `e` / `i` | Подобрать / надеть-использовать / спавнить только если нет в инвентаре |

Примеры: `spawn Wood 50`, `spawn Iron 30`, `spawn Troll 1 2`, `spawn SwordIron 1 1 e`.

### 5.2. Качество и количество

| Что | Как | Достоверность |
| --- | --- | --- |
| Количество | второй аргумент `spawn` | ✅ DLL |
| Качество предмета | **отдельной команды нет**; качество задаётся в `itemset <name> <itemLevel>` | ✅ DLL (справка `itemset`: «[item level override]») |
| Готовые сеты | `itemset Ashlands`, `itemset Meadows`, `itemset AshlandsMage`, `itemset Fisherman`… | 🟡 Host Havoc (список сетов) |
| Рыба | `catch <fish> [level]` | ✅ DLL |

⚠️ «Классическая» команда `item` из старых гайдов в 1.0.21 отсутствует — если UI показывает поле «item», его нужно мапить на `spawn`.

### 5.3. Как узнать prefab ID

1. **В игре:** `spawn ` + **Tab** — автодополнение по всем префабам сервера (самый точный способ для 1.0.21) 🟡.
2. **Поиск:** `find <text>` — ищет объекты по имени и ставит метки 🟡.
3. **Наш JSON:** `docs/admin-items.json` — 384 проверенных ID с русскими названиями и категориями.
4. **Дамп префабов:** Jotunn `prefab-list.md` (4 807 записей) — источник истины по регистру.

## 6. Удалённое администрирование

### 6.1. Vanilla: RCON и stdin отсутствуют ✅

| Проверка | Результат |
| --- | --- |
| RCON в мануале 1.0.21 | Не упомянут; перечислены только in-game команды `Kick/Ban/Unban/Banned` ✅ |
| Консоль сервера | Сервер запускается `-batchmode`; окно не является интерактивной консолью, команды в него не вводятся ✅ (мануал: остановка — CTRL+C, никаких команд) |
| stdin | Ванильный сервер не читает stdin; для этого пишут отдельные моды (ConsoleStdinHeeler) 🟡 |
| Итог | **Никакого удалённого выполнения команд в ванили нет.** Максимум — правка файлов + рестарт + чтение лога |

Практическое следствие для нашего приложения: **нельзя** отправить `save`/`kick`/`event` в процесс сервера. Единственные «команды» — аргументы запуска, файлы и сигналы процесса (корректная остановка = сохранение мира).

### 6.2. Моды (варианты удалённого/читерского администрирования)

| Мод | Что даёт | Что нужно | Риски / версии |
| --- | --- | --- | --- |
| **Server devcommands** (JereKuusela) | Включает `devcommands` для админов, добавляет утилиты и расширенный набор команд; клиентская часть + опциональная серверная | BepInEx 5 на клиенте админа (и на сервере для полного набора), запись в `adminlist.txt` | Iron Gate не поддерживает; ломается при апдейтах; конфиг `BepInEx/config/server_devcommands.cfg` 🟡 |
| **BepInExPack_Valheim** | Базовая платформа для всех модов (BepInEx 5 x64) | Ставится на сервер и/или клиент | Обязательная база; при 1.0 моды массово ломались 🟡 |
| **RCON-Next** (ferrinius) + мост **RCON-Next Valheim** | Source RCON по TCP с паролем; мост даёт «нативные» команды вроде `save` | Только сервер; BepInEx 5; `enabled=true`, `port` (по умолчанию 2458), `password` | RCON = полный админ-доступ, трафик не шифрован; без моста команд нет ✅ (README) |
| **ValheimRcon** (Thunderstore) | Серверный плагин RCON + «набор essential-команд» | Сервер + BepInEx | Набор команд ограничен; версии уточнять 🟡 |
| **Rcon Commands** (Thunderstore) | Выполнение команд на сервере через RCON | Сервер + RCON-плагин | 🟡 |
| **ConsoleStdinHeeler** (Nexus) | Читает stdin, роутит команды в `Terminal`, умеет `save`/`stop`/`players` | Сервер + BepInEx | Сторонний мод; не от Iron Gate 🟡 |

**Важно про «серверную консоль»:** Server devcommands **не** делает консоль сервера интерактивной и **не** добавляет stdin/RCON — он снимает запрет на `devcommands` для админа (клиентская часть) и добавляет серверные утилиты. Для команд «в процесс сервера» нужен отдельный RCON/stdin-мод (строки 3–6).

Ключевые предупреждения:

- ⚠️ Моды требуют **рестарта** сервера и установки в `BepInEx/plugins`; игроки без мода обычно могут играть, но часть функционала не увидят.
- ⚠️ Кросссплей-игроки (Xbox/PS5/Switch) модов не имеют — для них удалённая админка бесполезна.
- ⚠️ Любой мод — вне поддержки Iron Gate; после обновления игры сервер может не запуститься.
- ⚠️ RCON слушает TCP-порт: не выставлять в интернет без пароля/фаервола.

### 6.3. Что делать нашему приложению

| Сценарий | Решение |
| --- | --- |
| Ванильный сервер (по умолчанию) | управление файлами (`adminlist/bannedlist/permittedlist`), аргументы (`-preset/-modifier/-setkey`), рестарт, бэкапы, парсинг логов, корректная остановка (save) |

## 7. Игроки и ID из логов

### 7.1. Строки лога, из которых берутся имя и ID

| Строка (пример) | Что даёт | Замечания |
| --- | --- | --- |
| `Player history entry with index 0:  Игрок1 (Steam_76561198000000001, 1F9F5D73C109A8FB)` | Имя + платформенный ID + внутренний хеш | Самый удобный источник: имя и ID в одной строке 🟡 (наблюдение на нашем сервере) |
| `Got character ZDOID from NAME` | Имя персонажа | ID нет; только «кто зашёл» ✅/🟡 |
| `PlayFab socket ... received local Platform ID Steam_<id>` | Платформенный ID (кросссплей) | Префикс `Steam_`/`Xbox_`/… 🟡 |
| `Got connection SteamID <id>` | SteamID64 | Формат подтверждён low.ms для лога подключения 🟡 |

### 7.2. Как превратить это в строку `adminlist.txt`

| Платформа | В логе | В `adminlist.txt` |
| --- | --- | --- |
| Steam | `Steam_76561198000000001` или `76561198000000001` | `V_76561198000000001` (или `Steam_76561198000000001` — работает после 1.0.12) |
| Xbox / Game Pass | `Xbox_2535416401464117` | `X_2535416401464117` |
| PS5 / Switch 2 | `PlayStation_…` / `Switch_…` | `<Platform>_<ID>` без изменений 🟡 |

> ✅ Мануал: ID берётся «from the Server log or from within the game using the F2 panel». F2-панель — самый надёжный путь: там ID показан уже в нужном формате.

### 7.3. Практика парсинга

```regex
Player history entry with index \d+:\s+(?<name>.+?)\s+\((?<platform>Steam|Xbox|PlayStation|Switch)_(?<uid>\d+),\s*(?<hash>[0-9A-F]+)\)
Got character ZDOID from (?<name>.+)
Got connection SteamID (?<steamid>\d{17})
received local Platform ID (?<platform>Steam|Xbox|PlayStation|Switch)_(?<uid>\d+)
```

Правила:

1. **Имя может содержать пробелы** — брать всё до ` (` (ленивый `.+?`).
2. **ID регистрозависим** — не нормализовать регистр, не обрезать префикс.
3. Один игрок даёт **несколько** строк (подключение, персонаж, история) — дедуплицировать по `platform+uid`.
4. Строки `Player history entry` могут повторяться с разными `index` — это история, не «новые игроки» 🟡.
5. SteamID64 — 17 цифр, начинается с `7656…`; если в логе 16 цифр — это не SteamID64 ⚠️.
6. Если сервер кросссплейный (`-crossplay`), у части игроков вообще нет SteamID — только `Platform_ID` 🟡.

## 11. Внутриигровая панель — Valheim Admin Tool (F7)

Одна панель прямо в игре вместо консоли F5. Мод: **Valheim Admin Tool 0.5.8**
(QoLTeam/icecub, Thunderstore, Valheim 1.0.x; лицензия MIT; клиент + опционально
сервер). Официальные страницы:
[Thunderstore](https://thunderstore.io/c/valheim/p/QoLTeam/Valheim_Admin_Tool/),
[GitHub/страница мода](https://valheim.hexium.gg/mods/QOLTeam/Valheim_Admin_Tool),
[Nexus](https://www.nexusmods.com/valheim/mods/2916).

### Установка

Клиент (обязательно):
```
Valheim\BepInEx\plugins\ValheimAdminTool\ValheimAdminTool.dll
```
Сервер (опционально, но нужно для полного раздела TOOLS):
```
<server>\BepInEx\plugins\ValheimAdminTool\ValheimAdminTool.dll
```
Через скрипты репозитория:
```
scripts\install-client-mods.ps1 -ServerPath D:\Servers\Valheim\server
```
или готовый архив друзьям: `client-mods\Valheim-Client-Mods-DragAndDrop.zip`
(распаковать в папку игры; внутри инструкция).

Требования: BepInExPack_Valheim 5.4.2202+, SteamID в `adminlist.txt` сервера
в трёх форматах (`765…`, `Steam_765…`, `V_765…`), после добавления — рестарт
сервера. Панель открывается по **F7** (клавишу можно поменять в
`BepInEx\config\com.icecub.valheimadmintool.cfg`, затем About → Reload configuration).

### Русский интерфейс (F7)

У оригинального Valheim Admin Tool нет русского языка. В репозитории лежит
отдельный клиентский мод-переводчик
[`mods/vat-russian`](https://github.com/EZUBTS/valheim-server-manager/tree/main/mods/vat-russian):
BepInEx-плагин с Harmony-патчем на `UnityEngine.UI.Text.set_text`, который
подменяет английские подписи панели на русские и ставит системный шрифт с
кириллицей. DLL оригинального мода не изменяется.

Установка: распаковать `ValheimRuVatTranslation.dll` в
`Valheim\BepInEx\plugins\ValheimRuVatTranslation\` (или просто взять архив для
друзей из релиза — перевод уже внутри). Открытие панели остаётся на **F7**.

### Что внутри

- **CHEATS** — God Mode, Unlimited Stamina/Eitr, Fly/NoClip/FreeCam, No Build
  Cost, Build Everywhere, No Structural Damage, No Carry Limit, Infinite Jumps,
  Instant Crafting, Unrestricted Portals, Map Teleport (Shift+ЛКМ по карте),
  отключение потери вещей/еды/скиллов при смерти, корабельные читы, quick
  actions (heal, rested, boss powers, reveal map), fun-читы (moon gravity,
  super jump, giant/tiny, super knockback, bouncy mode).
- **SKILLS** — ползунки уровней всех навыков 0–100.
- **TIME / WEATHER** — время суток (midnight/sunrise/noon/sunset, заморозка),
  погода (presets, freeze).
- **SPEEDS** — ходьба/бег/плавание/полёт/езда 10–300%.
- **WORKBENCHES** — виртуальные верстаки: открыть крафт станции без постройки.
- **INVENTORY** — ряды инвентаря 1–9, максимальный вес.
- **ITEMS** — каталог всех предметов с поиском и категориями, выдача в инвентарь
  или спавн в мире с выбором качества.
- **CREATURES** — существа по биомам (включая Deep North/Ashlands), спавн рядом
  с выбором уровня и приручением.
- **TOOLS** — сброс данжей/ресурсов/природы, удаление дропа, сброс террейна,
  радиус подбора, телепорт к игроку / игрока к себе, кик/бан, обход вардов.
  Полный набор доступен админам, если панель стоит и на сервере.
- **ESP** — подсветка игроков, существ, дропа, ресурсов, данжей.
- **ABOUT** — версия, лог, перезагрузка конфига.

### Важные ограничения

- Без серверной части панели доступны читы, навыки, предметы, существа, ESP и
  локальные действия; кик/бан, телепорты, глобальное время и сброс дальних зон
  отключены (кнопки неактивны).
- Ставить панель на сервер нужно, только если хотите полный TOOLS; остальным
  игрокам панель не нужна.
- Читы могут отключить достижения в профиле игрока.
- Чужой сервер без панели: ваши клиентские читы и предметы работают, но действия
  TOOLS ограничены серверной стороной.
- Мод не является анти-читом; ограничить панель на сервере можно отдельным
  AntiValheimAdminTool (лежит в архиве мода как отдельный ZIP).
