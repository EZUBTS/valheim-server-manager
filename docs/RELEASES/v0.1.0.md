# Valheim Server Manager v0.1.0

Первый публичный релиз десктопного менеджера выделенного сервера Valheim для
Windows.

## Скачать

| Файл | Назначение |
| --- | --- |
| `Valheim Server Manager_0.1.0_x64_en-US.msi` | установщик MSI (Windows 10/11 x64) |
| `Valheim Server Manager_0.1.0_x64-setup.exe` | установщик NSIS |
| `valheim-server-manager.exe` | portable-версия (без установки) |
| `Valheim-Client-Mods-DragAndDrop.zip` | моды для клиента: BepInEx, Server Devcommands, Valheim Admin Tool (F7) и его русский перевод — распаковать в папку игры |
| `ValheimRuVatTranslation.dll` | только мод-переводчик панели F7 (для тех, у кого уже стоят BepInEx и Valheim Admin Tool) |

## Что внутри

- установка/обновление Valheim Dedicated Server через SteamCMD, запуск и
  корректная остановка с сохранением мира, живой лог, статус;
- списки игроков (`adminlist`/`bannedlist`/`permittedlist`), известные игроки из
  логов и истории мира;
- страница «Админ»: 7 разделов, 159 команд, 384 предмета, 65 существ,
  `-setkey`-переключатели, пресеты сложности, установка серверных модов;
- бэкапы миров, диагностика сети и брандмауэра (быстрая, без PowerShell);
- внутриигровая панель **F7** (Valheim Admin Tool) с русским интерфейсом;
- архив для друзей «распаковать в папку игры».

## Установка

1. Запустить установщик (или portable `.exe`).
2. «Сервер» → установить SteamCMD → установить сервер.
3. «Мир» → имя/мир/пароль/порт/crossplay → сохранить.
4. «Обзор» → «Запустить»; проверить сеть на странице «Сеть».
5. Для читов: «Админ» → «Установить моды»; клиентскую часть поставить архивом
   из этого релиза и зайти в игру (F7).

Подробности — в [README](https://github.com/EZUBTS/valheim-server-manager#readme)
и [docs/ADMIN-REFERENCE.md](https://github.com/EZUBTS/valheim-server-manager/blob/main/docs/ADMIN-REFERENCE.md).

## Требования

Windows 10/11 x64, WebView2 Runtime, ~4 ГБ диска под сервер и SteamCMD
(плюс место под бэкапы). Для игры по сети — открытые UDP-порты 2456–2458 либо
crossplay по коду приглашения.

## Проверено

- `cargo test` — 170 тестов, `clippy -D warnings`, `rustfmt`;
- frontend — typecheck, oxlint, 139 тестов, production build;
- полный e2e на реальном сервере: старт (13–16 с), маркеры готовности, корректная
  остановка с сохранением мира, диагностика сети, бэкапы.

## Известные ограничения

- нет установки произвольных модов через GUI (только BepInEx + Server Devcommands
  и клиентский набор из релиза);
- RCON/удалённой консоли в Valheim нет;
- Snap Layouts Windows 11 для frameless-окна не поддерживается;
- проброс портов на роутере приложение не настраивает — только проверяет
  брандмауэр и подсказывает.
