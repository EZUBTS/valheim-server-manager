# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[Semantic Versioning](https://semver.org/lang/ru/).

## [0.1.0] — 2026-11-09

Первый публичный релиз.

### Добавлено

- Десктопное приложение **Valheim Server Manager** (Tauri 2 + Rust, React 19 +
  TypeScript + Vite + Tailwind 4) для Windows 10/11.
- Установка и обновление Valheim Dedicated Server через SteamCMD, запуск и
  корректная остановка сервера (Ctrl+C с сохранением мира), статус, живой лог.
- Управление игроками: `adminlist.txt`, `bannedlist.txt`, `permittedlist.txt`,
  парсинг известных игроков из логов и истории мира.
- Страница **«Админ»** с семью разделами: обзор, игроки, читы, предметы,
  мир, моды, справка; каталог 159 команд, 384 предмета и 65 существ, генераторы
  `spawn`/`itemset`, переключатели `-setkey`, пресеты сложности.
- Резервные копии миров (zip), авто-бэкапы перед обновлением и остановкой,
  восстановление с защитной копией.
- Диагностика сети: UDP-порты 2456–2458, брандмауэр Windows, локальные IP.
  Диагностика переписана на точечные `netsh`-запросы с таймаутами и TTL-кэшем:
  ~0,4 с вместо 80+ с на машине с большим числом правил firewall.
- Установка серверных модов BepInExPack_Valheim + Server Devcommands в один клик.
- Архив для друзей «распаковать в папку игры»: BepInEx, Server Devcommands,
  **Valheim Admin Tool** (внутриигровая панель F7) и её **русский перевод**.
- Отдельный мод-переводчик `mods/vat-russian` — переводит интерфейс
  Valheim Admin Tool на русский, не изменяя DLL оригинального мода.

### Исправлено

- SteamCMD, завершающийся с кодом 7 при успешной установке, больше не считается
  ошибкой.
- Дублирование сообщений о готовности сервера и коде приглашения в логе.
- `Get create world` больше не трактуется как создание нового мира: для
  существующего мира показывается корректная загрузка, готовность не сбивается.
- Ложные утверждения об отсутствии правила брандмауэра на русской локали
  Windows (`Включен`/`Вход`).

### Известные ограничения

- Нет установки произвольных модов через GUI (только BepInEx + Server Devcommands
  и клиентский набор из релиза).
- Нет RCON/удалённой консоли (у Valheim её нет); удалённое администрирование —
  через моды или файлы списков игроков.
